## API 与宿主删除范围

- Android 原 ScannerPreviewView 构造不变；新增 setFeedbackEnabled(enabled:Boolean,vibrateEnabled:Boolean=false)，默认不开启。ZXing 原 BeepManager 源码默认 beep=true/vibrate=false，生产宿主未修改振动，因此显式 true 保留原声音行为。有效回调停止后一次反馈；迟代次/暂停/释放不反馈；媒体失败不丢有效结果。
- OHOS 新 GycScannerPreviewView.VIEW_NAME='GycScannerPreviewView'，props running/scanFrameSize(vp)/onResult/onFailure 沿用生产。customScan init/start/rescan/stop/release 归组件；全实例唯一 owner/队列，旧相机成功 release 才允许新 init，stop 失败仍尝试 release。开始异步释放即撤帧代次，旧 View destroy 不释放新 owner。
- scanner-kuikly 新 ScannerPreviewView/Attr/Event 与 ViewContainer.ScannerPreview DSL。typed props/安全事件 JSON 解析归组件，Compose 宿主只做 MakeKuiklyComposeNode 装配。现 ScannerModule 图片解码没有新增平行实现。
- 宿主删除 Android BeepManager 调用、AppScannerPreviewView.ets 的原生状态机、Kuikly ScannerPreview.kt 的私有 View/JSON parser。权限、相册、业务准入、扫码框、状态栏和页面 UiState 保留。

完整接线见 docs/接入指南.md#嵌入式预览与反馈待发布。
