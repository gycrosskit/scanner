# scanner 0.1.5 远程发布验收

## 候选范围

Maven `scanner-core` / `scanner-kuikly` 候选 `0.1.5`，公开 API 保持兼容。Kuikly 后台取消将 pending/callback 清理派回调用时的页面 dispatcher，移除后清空 callbackRef，防止注册期间取消的重复注销；保留 disposed 和迟结果消费校验。

`decode`、`scanCode` 和 `dispose` 必须在所属页面 Kuikly Context 调用，页面 dispatcher 不能由 Default/IO/Unconfined 替代。清理不依赖已取消的 Job。

原生 HAR/Swift 源码未变，分别保持 `0.1.3` / `0.1.1`。旧渠道验收只适用于对应历史版本，不作为本候选的验收结果。
