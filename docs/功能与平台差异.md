## 产物与职责

| 模块/产品 | 实际职责 |
|---|---|
| `scanner-core` | QrCodeDecoder、Android ZXing decoder / ScannerPreviewView、IosQrCodeDecoder桥；不含CMP Composable。 |
| `scanner-kuikly` | Android/iOS/OHOS目标：ScannerPreviewHost（Kuikly Compose）、类型化Attr/Event；ScannerModule的系统扫码能力实际连接OHOS Renderer，Android/iOS不自动获得同名native Module。 |
| `GycScannerNative` | iOS15+ Swift Package产品；CoreImage图片解码、AVFoundation预览。 |
| `@gycrosskit/scanner-native` | API22 HAR；GycScanner系统扫码/图片解码、GycScannerPreviewView嵌入预览及GycScannerModule。 |

构建边界：[core构建](../scanner-core/build.gradle.kts)、[Kuikly构建](../scanner-kuikly/build.gradle.kts)、[模块清单](../settings.gradle.kts)、[OHOS SDK配置](../ohos/build-profile.json5)。

除上表明确的 UI 入口外，本库没有独立 CMP 页面模块。Android/iOS 可由宿主原生适配把同一能力供 CMP 与 Kuikly 使用；“可注入两套UI”不代表库自动完成宿主接线、同名 Renderer 注册或品牌验收。

## 五入口功能矩阵

“原生实现，宿主注入”表示平台能力已有源码，CMP/Kuikly由宿主适配接入；“OHOS Module已实现”表示已有Kotlin/ArkTS调用链。矩阵说明功能接入边界，实际行为验证见下方验证范围。

| 功能/API组 | CMP Android | CMP iOS | Kuikly Android | Kuikly iOS | Kuikly OHOS |
|---|---|---|---|---|---|
| 图片QR解码 | 原生实现，宿主注入 | Swift桥，宿主注入 | 原生实现，宿主注入 | Swift桥，宿主注入 | OHOS Module已实现 |
| 嵌入相机预览 / ROI / running | Android View，宿主注入 | UIView，宿主注入 | Host+宿主注册Android View | Host+宿主注册UIView | Host+HAR View |
| 统一反馈回调 | 宿主注入回调 | 宿主注入回调 | Host onFeedback | Host onFeedback | Host onFeedback |
| 系统扫码页 scanCode | 不支持本库此入口 | 不支持本库此入口 | 未提供Android Module | 未提供iOS Module | OHOS Module已实现 |

## 公开 API 组

- `QrCodeDecoder.decode(bytes)`：原始QR文本或null；`ScannerModule.scanCode()`：仅OHOS系统扫码，取消null、SDK失败抛错。
- A `ScannerPreviewView.setScanFrameSize(px)` / `setRunning` / `setFeedbackEnabled` / `setFeedbackHandler` / `release()`；i UIView的对应边界为`setScanFrameSize(points)` / `setRunning` / `setFeedbackHandler` / `releaseCamera()`。
- Kuikly `ScannerPreviewHost(running,onResult,onFailure,modifier,scanFrameSize=260.dp,onFeedback=null)`；typed Attr/Event只有running、scanFrameSize、onResult、onFailure。

## API 合同与差异分类

| 分类 | 具体输入 / OS / SDK边界 | 调用方应如何处理 |
|---|---|---|
| 组件边界 | 图片decoder输入为空或>32MiB：Kotlin/Swift返回null；OHOS底层invalid_content经ScannerModule映射null。 | 候选统一Android/iOS与OHOS输入上限，未识别/坏图返回null；原生ArkTS仍有结构化状态，不能混同两层返回类型。 |
| 组件边界 | 预览默认260dp（A）、260points（i）、260vp（O）；A setScanFrameSize参数是px，Swift是points。 | KuiklyHost默认260.dp并传逻辑尺寸，宿主Android适配需按density换算；不是把260当同一物理像素数。 |
| 组件边界 | 公开Attr只有running、scanFrameSize；事件onResult/onFailure；Host onFeedback默认null。 | 不提供公共torch/paused协议。A额外setFeedbackEnabled默认关闭声音/振动；使用统一反馈时避免双重开启。 |
| 厂商限制 | OHOS要求设备提供ScanKit，纯OpenHarmony不保证提供。 | 系统scanCode只能OHOS使用；busy/cancelled/permission_denied/failed不同；dispose抑制尾批但不能主动关闭系统扫码页。 |
| 宿主职责 | A API24+；iOS15+；OHOS目标/兼容API22。 | 宿主先申请CAMERA、注册各平台原生View、挂载预览并处理running/页面退出；扫码框、图片选择、原始文本业务校验归宿主。 |
| 未验收 | 真实相机/旋转/手电筒硬件、三端同图准确率和多品牌页面。 | Swift Simulator ROI/真实CoreImage helper通过也不证明真实摄像头。 |

## 验证范围

本轮源码修复验证：`IosQrCodeDecoderTest` 用真实 Job 检查进入前和桥调用中取消；Android 对应回归覆盖同 Default dispatcher 的 Job 取消和解码器抛 CancellationException。`ScannerPreviewEventTest` 和 Module 生命周期测试直接编译生产 Kotlin，检查对象/JSON 字符串中的空白内容与空/非法数据；Kuikly JSON/renderer 边界为替身；本轮另通过实际 Kuikly iOS Simulator KLIB 编译，仍不代表 Renderer 设备行为已验收。

以下结果都执行实际生产函数或状态机；平台SDK、系统UI、网络及传输替身的范围单独注明，静态源码文本检查不作为行为通过证据。前轮结果指2026-10-08代码复核已有日志/XML，本轮只复用。

| 时点 | 执行平台 / 入口 | 实际覆盖合同 | 结果及边界 |
|---|---|---|---|
| 前轮代码复核，复用 | Android Robolectric 3例；iOS Kotlin/Native Simulator 1例 | [Android测试](../scanner-core/src/androidUnitTest/kotlin/io/github/gycrosskit/scanner/AndroidQrCodeDecoderTest.kt)、[反馈测试](../scanner-core/src/androidUnitTest/kotlin/io/github/gycrosskit/scanner/ScannerFeedbackTest.kt)及[iOS桥测试](../scanner-core/src/iosTest/kotlin/io/github/gycrosskit/scanner/IosQrCodeDecoderTest.kt)：真实QR像素、空/坏图、32MiB超限、反馈代次、暂停/释放 | 全部通过；本轮未重跑 |
| 前轮代码复核，复用 | Swift CoreImage真实解码；iOS Simulator ROI fixture 10项；Node OHOS预览状态机 | [解码fixture](../tests/scanner-decode.swift)、[ROI fixture](../tests/run-scanner-roi.py)、[OHOS预览](../tests/scanner-preview.cjs)：默认260、区域重叠、一次结果、旧帧、同步start、相机owner交接和release失败重试 | 通过；ROI使用受控metadata，未真实拍摄 |
