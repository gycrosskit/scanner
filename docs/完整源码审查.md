## 最低系统与线程

Android：API24+；iOS：iOS15+（Swift Package 基线；KMP bridge 需宿主原生实现）；OHOS：实际 target/compatible API22。解码与预览各自沿用现有线程边界；Android UI 和 Swift camera/session 生命周期由原生视图控制，OHOS 预览共享 session 的 owner/generation 防止旧回调交付。

## 公开调用链

- QrCodeDecoder → Android ZXing / iOS CoreImage / Kuikly ScanKit；Android 复用 Media 采样，不创建原图 Bitmap 后再缩放。
- Android/Swift 原生 ScannerPreviewView → camera session / 图层与扫描框 → 主线程开始/停止和首次结果门禁。
- Kuikly ScannerModule / ScannerPreviewView → GycScannerModule / GycScannerPreviewView → Surface、全局 session owner、generation 与 stop/release；Index 导出原生入口。
